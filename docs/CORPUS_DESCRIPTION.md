## Weight Range Summary

Weights computed by Algorithm 1 of [Maredj et al. 2024], P_start=3.0:

| Property | Value |
|---|---|
| Global weight minimum | -0.500 |
| Global weight maximum | 3.000 |
| Global weight mean (positive only) | 2.178 |
| Units with negative weight | 4 (deeply-nested, high-orbit satellites; see note below) |
| Global max orbit depth | 3 |

**Note on negative weights.** The weight formula of [Maredj et al. 2024]
(`w(v) = Pp - 1 - orbit/denom`) can produce a negative value for a satellite
placed at a high orbit number under a predecessor of already-low weight —
an accepted edge case of the published formula, not an annotation error.
Downstream metrics that aggregate weight (e.g. Coverage Score) treat any
negative per-unit weight as contributing 0, not a negative amount, since a
"negative importance" unit has no meaningful negative contribution to a
coverage fraction.
